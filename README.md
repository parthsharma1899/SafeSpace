# SafeSpace

Multimodal stress estimation: four independent models score stress from wrist
signals, typed text, voice and a face photo, and a fusion layer combines whatever
is available into one score over time.

> **Research demo, not a diagnostic tool.** The models are proxies (facial
> expression and acted speech are not stress), the datasets are small, and no
> result here should be used to make a decision about a real person. Nothing a
> user enters in the demo is stored.

## What's in it

- **A fusion method** (`src/safespace/fusion/`): the original residual-persistence
  rule from the project's paper, ported exactly as `v1`, and a redesign `v2` that
  is unbiased and cannot crash. Both are benchmarked against simple baselines on a
  score-level simulator.
- **Four modality models** (`src/safespace/models/`), each with a measured model
  card in `docs/models/`.
- **A FastAPI backend** (`src/safespace/api/`) and a **React frontend** (`web/`)
  with a client-side fusion playground and a live check-in demo.

## Results

All numbers are regenerated by the scripts named below; none is hand-typed.

### Fusion (held-out simulated seeds, mean absolute error, lower is better)

| scenario average | v1 (paper) | smoothed mean | smoothed median | v2 |
|---|---:|---:|---:|---:|
| error | 0.1292 | 0.0681 | 0.0619 | 0.0573 |

v2 meets 3 of 4 pre-registered targets; it misses "beats v1 in every scenario"
in the one case where a single modality is right and the rest miss it. On real
held-out model scores (virtual subjects), v2 (MAE 0.126) beats v1 decisively
(0.230, badly biased) but ties a tuned smoothed mean when all modalities are
reliable. See `docs/fusion.md`, `results/fusion_benchmark.md`,
`results/virtual_subjects.md`.

### Models

| model | measure | script | card |
|---|---|---|---|
| Wrist (XGBoost, WESAD) | leave-one-subject-out AUC **0.9512**, accuracy 0.8899 (majority 0.6830) | `scripts/train_wrist.py` | [card](docs/models/wrist.md) |
| Text (BERT, Dreaddit) | accuracy **0.9077** / AUC 0.9669 (training split unknown) | `scripts/eval_text.py` | [card](docs/models/text.md) |
| Voice (CNN, RAVDESS) | accuracy **0.9424** (same actors in train/test) | `scripts/eval_voice.py` | [card](docs/models/voice.md) |
| Face (ResNet+ViT+ELM, FER-2013) | as saved: AUC 0.51 (chance); ELM output layer re-fit to AUC **0.7025** | `scripts/eval_face.py`, `scripts/refit_face_elm.py` | [card](docs/models/face.md) |

Every claim in the original paper draft and its status is tracked in
`docs/claims.md`.

## Install

```bash
python3 -m venv .venv && source .venv/bin/activate
python -m pip install -e ".[dev,bench]"        # fusion, simulator, tests
python -m pip install -e ".[models,api]"       # to run the real models and API
```

On macOS, XGBoost needs OpenMP: `brew install libomp` (or prefix commands with
`DYLD_FALLBACK_LIBRARY_PATH=$(python -c 'import sklearn,os;print(os.path.join(os.path.dirname(sklearn.__file__),".dylibs"))')`).

## Run the tests

```bash
pytest -q
```

Tests that need a dataset or trained weights skip automatically when those are
absent, so the suite passes on a clean clone.

## Reproduce each result

Datasets download into `data/` (gitignored); weights live in `artifacts/`
(gitignored). See `docs/datasets.md` for sources and licences.

```bash
python scripts/run_fusion_benchmark.py        # results/fusion_benchmark.md + figures
python scripts/train_wrist.py                 # results/wrist_loso.md  (needs WESAD)
python scripts/eval_text.py                    # results/text_eval.md   (needs Dreaddit)
python scripts/eval_voice.py                   # results/voice_eval.md  (needs RAVDESS)
python scripts/eval_face.py                    # results/face_eval.md   (needs FER-2013)
python scripts/refit_face_elm.py               # results/face_refit.md  (needs FER-2013)
python scripts/fit_calibration.py              # results/calibration.md
python scripts/run_virtual_subjects.py         # results/virtual_subjects.md
```

## Run the demo

```bash
# backend (localhost only, no debug)
uvicorn safespace.api.app:app --host 127.0.0.1 --port 8080
# frontend
cd web && npm install && npm run dev
```

Set `SAFESPACE_API_STUB=1` to run the API with fixed stub scores and no weights.
For the High-stress support message, set `GEMINI_API_KEY` and `GEMINI_MODEL`
(without them, a fixed message is used). The ESP32 wearable streams through
`scripts/wearable_bridge.py`.

## Ethics and limits

- Facial expression and acted speech are proxies for stress, not stress itself.
- The wrist model is validated on 15 lab subjects on one device; the text model
  may have seen its test posts in training; the voice test shares speakers across
  train and test. Each card states its own limits.
- The demo stores nothing and runs models in memory; uploads are deleted before
  the response returns.
